# med-index

Переиндексация направлений и регистра показателей.

## Использование
```
/med-index
```

## Инструкции

### Шаг 1. Сканирование
Найди все MD в `Документы/`. Из frontmatter извлеки: date, type, direction,
category, metrics (для анализов).

### Шаг 2. Файлы направлений
Для каждого направления перезапиши `Направления/{Направление}.md`: сгруппируй
ссылки по годам (новые сверху), внутри года — по типу документа, формат
`[[путь|Дата - Описание]]`. Пустые разделы пропускай. Если встретилось новое
направление без файла — создай.

### Шаг 3. Регистр показателей — статистика через код
Пересобери `Показатели/_registry.md`. Для каждого уникального показателя
(имя+единицы = ключ) посчитай **исполнением кода**, не в уме: число измерений,
период, последнее значение и статус, тренд — по тому же правилу тренда, что
в med-metrics Шаг 2 (±10% от среднего двух предыдущих измерений). Отдельной
таблицей — показатели, где последнее значение вне нормы. При сомнении в
референсе сверь через MCP `medrag` (коллекция `medrag_textbooks`).

### Шаг 4. Отчёт
Выведи: документов по направлениям, всего уникальных показателей, сколько вне
нормы, что обновлено.

## Примечание
Показатели с одинаковым именем, но разными единицами — разные показатели.
При повторном запуске файлы направлений и регистр перезаписываются.
