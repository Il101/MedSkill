# med-history

История болезни по направлению. Сохраняется в `Истории/{Направление}.md`.

## Использование
```
/med-history Гастроэнтерология
/med-history Кардиология
```

## Инструкции

### Шаг 1. Сбор документов
1. Возьми направление из аргумента.
2. Собери все документы из `Документы/`, где `direction` = указанное.
3. Прочитай каждый полностью. Если документов нет — сообщи и заверши.

### Шаг 2. Извлечение
По каждому документу вытащи: даты, врача, жалобы, диагнозы (+ коды МКБ),
назначения, показатели вне нормы, заключения исследований, данные выписок.

### Шаг 3. Динамика показателей — расчёты через код
Тренды и сравнение «первое/последнее» значение считай исполнением кода,
не в уме, по тому же правилу тренда, что в med-metrics (±10% от среднего
двух предыдущих измерений; см. Шаг 2 там). Отнесение к норме сверяй с нормой
из документа; при её отсутствии — через MCP `medrag` (коллекция
`medrag_textbooks`, референс на английском).
База знаний — только для проверки референсов и стандартных интервалов
скрининга, НЕ для вывода о причинах.

### Шаг 4. Отчёт
Сохрани `Истории/{Направление}.md` с frontmatter (direction, generated,
period_start/end, documents_count, diagnoses[]) и разделами: резюме,
диагнозы (таблица), хронология по годам, динамика показателей, лечение,
рекомендации по дообследованию (чек-лист), **вопросы для врача**.

### Шаг 5. Логика рекомендаций
- анализ не сдавался > 1 года или был вне нормы → предложить контроль;
- исследование не проводилось > 2 лет или выявлена патология → оценить динамику;
- нет осмотра > 1 года → предложить визит.
Стандартные интервалы скрининга по направлению при необходимости сверь через
`medrag`, а не по памяти.

### Шаг 6. Дисклеймер
В конце файла: отчёт собран из документов, референсы сверены с базой знаний;
рекомендации и вопросы — основа для разговора с врачом, не диагноз и не
назначение.

## Примечание
Анализируются только документы с этим `direction` в frontmatter. При повторном
запуске файл истории перезаписывается актуальными данными.
