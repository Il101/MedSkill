# med-merge-history

Сводный обзор по всем направлениям. Сохраняется в `Истории/_Сводная.md`.

> **Это НЕ диагностика.** Скил собирает разрозненные данные в одну картину и
> формулирует вопросы к врачу. Он НЕ ставит диагнозы, НЕ присваивает
> «достоверность» связям и НЕ подтверждает корреляции. Данные одного человека —
> это выборка n=1: совпадение по времени ≠ причинность. Любую замеченную связь
> подаём как вопрос для специалиста, а не как вывод.

## Использование
```
/med-merge-history
```

## Инструкции

### Шаг 1. Сбор
Прочитай все файлы из `Истории/` (кроме `_Сводная.md`). Извлеки из frontmatter
направление, диагнозы со статусами, период, число документов.

### Шаг 2. Единая картина
- Все диагнозы, сгруппированные по статусу (активные / ремиссия / сняты) и по
  системам органов.
- Единая хронология событий по датам (отметь совпадения по времени как
  наблюдение, без причинных выводов).
- Показатели, упоминаемые в нескольких направлениях; расчёты — через код.

### Шаг 3. Возможные пересечения — как ВОПРОСЫ
Если у пользователя встречаются состояния, которые в медицине иногда связаны
(например: ожирение + давление + липиды; диабет + почки/сосуды; хронический
гастрит + анемия; щитовидная железа + сердце), — **не утверждай связь**.
Сформулируй это как вопрос к врачу:

> «У вас в разных направлениях встречаются X и Y. Стоит спросить у врача,
> связаны ли они и нужно ли смотреть их вместе.»

**НЕ присваивай "достоверность высокая/средняя/низкая"** — за такой меткой нет
статистики, она создаёт ложную уверенность. **НЕ обращайся к базе знаний
`medrag` для обоснования связей у пациента** — база подтвердит лишь, что связь
в принципе существует, но не то, что она есть у этого человека; это усилит
ложную авторитетность. База знаний в этом скиле не используется.

### Шаг 4. Пробелы в наблюдении
Отметь области, где давно не было обследования (по датам из историй) — как
пункты «спросить, не пора ли повторить», без указания медицинских интервалов
из памяти.

### Шаг 5. Сохрани `Истории/_Сводная.md`
Frontmatter: generated, period_start/end, directions_count,
active_diagnoses_count. Разделы:
- Общая картина (нейтральное описание, без диагнозов)
- Сводка по направлениям (таблица)
- Активные диагнозы по системам органов
- **Вопросы к врачу** (главный раздел — сгруппируй: по возможным пересечениям,
  по динамике показателей, по пробелам в наблюдении)
- Единая хронология
- Показатели, требующие внимания (только факт отклонения + «обсудить с врачом»)

### Шаг 6. Вывод
Кратко: сколько направлений и активных диагнозов, и 3-5 главных вопросов,
которые стоит задать врачу.

### Дисклеймер (обязателен в файле)
```
Это сводка ваших собственных медицинских записей, подготовленная для разговора
с врачом. Не является медицинским заключением. Замеченные пересечения — поводы
для вопросов, а не установленные связи. Все выводы делает врач.
```
