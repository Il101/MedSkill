# med-merge-history

Сводный анализ по всем направлениям с корреляциями и гипотезами. Сохраняется
в `Истории/_Сводная.md`.

> Гипотезы строятся на данных одного человека (n=1): совпадение по времени
> и попадание под текстовые критерии синдрома — не то же самое, что
> подтверждённый диагноз. Диагностические критерии, которые упоминаются в
> гипотезе, сверяются по базе знаний `medrag`, а не берутся по памяти модели —
> это снижает риск перепутать пороги/цифры конкретного синдрома. Но сама база
> знаний не может сказать, есть ли синдром у ЭТОГО человека — это вопрос
> клинической оценки, а не поиска по учебнику. Достоверность/вероятность,
> указанная в отчёте, всегда означает **«насколько чётко данные пациента
> попадают под текстовые критерии источника»**, а не «вероятность того, что
> диагноз верен у этого пациента» — эти вещи разные, и путать их нельзя.

## Использование
```
/med-merge-history
```

## Инструкции

### Шаг 1. Сбор
Прочитай все файлы из `Истории/` (кроме `_Сводная.md`). Извлеки из frontmatter
направление, диагнозы со статусами, период, число документов.

### Шаг 2. Единая картина
- Все диагнозы, сгруппированные по статусу (активные / ремиссия / сняты) и по
  системам органов.
- Единая хронология событий по годам.
- Показатели, упоминаемые в нескольких направлениях; расчёты — через код
  (см. med-metrics).

### Шаг 3. Корреляционный анализ

Проверь известные медицинские связи между выявленными диагнозами/показателями
(ориентиры для того, какие паттерны вообще стоит проверять — не исчерпывающий
список и не источник точных цифр: пороги и критерии сверяются в Шаге 4,
а не берутся из этого списка):

**Метаболические:**
- Ожирение + гипертония + дислипидемия → метаболический синдром
- Сахарный диабет + кардиопатия + нефропатия → диабетические осложнения
- Гипертиреоз/гипотиреоз + кардиальные нарушения → тиреогенная кардиопатия

**ЖКТ и системные:**
- Хронический гастрит + анемия → возможный дефицит B12/железа
- Мальабсорбция + остеопороз → недостаток кальция/витамина D
- Хронические заболевания печени + коагулопатия

**Кардио-ренальные:**
- Сердечная недостаточность + почечная недостаточность → кардиоренальный синдром
- Артериальная гипертензия + хроническая болезнь почек → нефрогенная гипертензия
- Ишемическая болезнь сердца + сахарный диабет → ускоренный атеросклероз

**Неврология и другие:**
- Мигрень + кардиоваскулярные нарушения → сосудистый компонент
- Полинейропатия + сахарный диабет → диабетическая нейропатия
- Когнитивные нарушения + сосудистая патология → дисциркуляторная энцефалопатия

**Аутоиммунные:**
- Множественные аутоиммунные проявления в разных органах → полиаутоиммунность
- Аутоиммунное заболевание + семейный анамнез → генетическая предрасположенность

Также отметь временные корреляции (события в близкие даты) и показатели,
устойчиво отклоняющиеся в нескольких анализах.

### Шаг 4. Фактчек критериев через medrag — ОБЯЗАТЕЛЕН перед выводом гипотезы

Прежде чем назвать паттерн (например «похоже на метаболический синдром») и
присвоить ему достоверность, сверь его диагностические критерии через
MCP-инструмент базы знаний:

- запрос вида `"<название синдрома> diagnostic criteria"` к коллекции
  `medrag_textbooks` (на английском, результат интерпретируй по-русски);
- в отчёте укажи, каким именно критериям (пороги, число признаков) соответствуют
  данные пациента, и процитируй/укажи источник — не пиши критерии по памяти;
- если найденные в базе критерии расходятся с тем, что подразумевалось в
  Шаге 3 — используй то, что нашла база, и отметь расхождение;
- если medrag недоступен или ничего не нашёл — прямо напиши в отчёте, что
  критерии не сверены по источнику, и понизь метку достоверности.

**Достоверность/вероятность гипотезы** = насколько полно данные пациента
закрывают найденные критерии (например: «3 из 5 критериев ATP III» →
высокая; «1 из 5» → низкая). Это НЕ вероятность того, что диагноз есть у
пациента — так и формулируй в отчёте.

### Шаг 5. Пробелы в наблюдении
Отметь области, где давно не было обследования (по датам из историй), с
рекомендуемой частотой скрининга.

### Шаг 6. Сохрани `Истории/_Сводная.md`

Frontmatter: generated, period_start/end, directions_count,
active_diagnoses_count, hypotheses (name, confidence, criteria_source,
requires_investigation).

Разделы:
- Общая картина
- Сводка по направлениям (таблица)
- Все диагнозы по системам органов
- **Корреляционный анализ** — выявленные связи с фактами и достоверностью
- **Гипотезы о системных проблемах** — для каждой: обоснование, критерии
  источника (со ссылкой на medrag), достоверность (с пояснением, что она
  означает — см. выше), рекомендуемые исследования для подтверждения/опровержения
- Единая хронология
- Показатели, требующие внимания
- Комплексный план обследования (приоритеты)
- Вопросы для обсуждения с лечащим врачом

### Шаг 7. Вывод
Кратко: сколько направлений и активных диагнозов, ключевые гипотезы с
достоверностью и источником критериев, приоритетные обследования.

### Дисклеймер (обязателен в файле)
```
Сводный отчёт сформирован автоматически на основе историй болезни по
направлениям. Диагностические критерии сверены по базе медицинских знаний,
но применимость к конкретному пациенту определяет только врач. Достоверность
гипотезы означает степень соответствия критериям источника, а не вероятность
диагноза. Не является медицинским заключением.
```
