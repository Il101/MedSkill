# MedVault — плагин для личной медицинской документации в Obsidian

Форк [kotkaktot/MedSkill](https://github.com/kotkaktot/MedSkill), доработанный:
исправлен формат скилов, устранены риски потери данных, добавлен локальный
RAG-слой (MedRAG) для проверки референсов и фактов.

> **Не диагностический инструмент.** Плагин ведёт учёт, считает динамику и
> готовит вопросы к врачу. Он не ставит диагнозы. RAG проверяет факты
> (нормы, критерии), но не решает, есть ли связь у конкретного пациента.

## Что изменено против оригинала

- `skill.md` → `SKILL.md` + YAML frontmatter (автоактивация работает)
- `med-process-inbox`: оригиналы **перемещаются** в `_processed/`, не удаляются;
  убрано авто-удаление «не распознан/повреждён»
- `med-metrics`: расчёты через исполнение кода, референсы сверяются с базой знаний
- `med-merge-history`: убрана псевдо-метрика confidence; вывод переобрамлён
  из «гипотезы» в «вопросы к врачу»; база знаний НЕ используется для гипотез

## Установка

### 1. База знаний (один раз)
```bash
cd rag
pip install chromadb datasets
python build_index.py     # скачает MedRAG/textbooks и построит локальный индекс
```
Всё локально: default-эмбеддинги (sentence-transformers), без API-ключей.

### 2. Плагин
```
/plugin marketplace add <твой-форк>
/plugin install medvault@<твой-форк>
```
При активации Claude Code сам поднимает локальный `chroma-mcp` (см. `.mcp.json`).

### 3. Vault
```
/med-init      # в пустой директории — создаёт структуру vault
```

## Приватность
База знаний и индекс не покидают твою машину. Но содержимое твоих документов
уходит в Claude API в момент чтения агентом — это свойство Claude Code,
RAG на него не влияет.

## Стек (всё бесплатно, Apache 2.0 / открытые лицензии)
ChromaDB · chroma-core/chroma-mcp · sentence-transformers (локально) · MedRAG Textbooks
