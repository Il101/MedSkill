# Skill: med-metrics

Визуализация динамики медицинских показателей.

## Описание

Этот skill анализирует все анализы в медицинском хранилище, показывает динамику показателей в виде графиков и сохраняет отчеты в хранилище.

## Использование

```
/med-metrics                           # Список всех показателей
/med-metrics Глюкоза                   # График динамики глюкозы
/med-metrics "Холестерин ЛПНП"         # Показатель с пробелами
/med-metrics Глюкоза,Гемоглобин        # Сравнение нескольких показателей
/med-metrics --abnormal                # Только показатели вне нормы
```

## Что делает skill

1. Собирает все измерения показателя из анализов
2. Строит график динамики (ASCII + Mermaid)
3. Рассчитывает статистику (мин/макс/среднее/тренд)
4. **Сохраняет отчет в `Показатели/{Показатель}.md`**
5. **Обновляет ссылки в `Показатели/_registry.md`**

## Инструкции

### Шаг 1: Сканирование анализов

1. Найди все MD файлы в `Документы/Анализы/`
2. Для каждого файла извлеки из YAML frontmatter:
   - `date` - дата анализа
   - `metrics` - массив показателей с полями: name, value, unit, norm, status

### Без аргументов — список всех показателей

Выведи таблицу всех показателей:

```
## Все показатели

| Показатель | Измерений | Период | Последнее | Тренд |
|------------|-----------|--------|-----------|-------|
| [[Показатели/Глюкоза\|Глюкоза]] | 5 | 2021-2025 | 5.2 ммоль/л (норма) | → |
| [[Показатели/Гемоглобин\|Гемоглобин]] | 8 | 2019-2025 | 148 г/л (норма) | ↑ |
| [[Показатели/СКФ\|СКФ]] | 2 | 2021-2022 | 79 мл/мин (низкий) | ↓ |

**Условные обозначения:**
- ↑ рост, ↓ снижение, → стабильно, — недостаточно данных
```

### Интерактивный выбор показателя

После вывода таблицы всех показателей, предложи пользователю выбрать показатель для детального анализа.

Используй инструмент `AskUserQuestion` с параметрами:
- **question:** "Какой показатель хотите проанализировать подробнее?"
- **header:** "Показатель"
- **options:** 4 самых важных/часто измеряемых показателя из списка (приоритет — показатели вне нормы)

После выбора пользователя — построй график динамики и сохрани отчет.

### С аргументом — график динамики и сохранение

#### Шаг 2: Сбор данных показателя

1. Найди все измерения указанного показателя
2. Отсортируй по дате (от старого к новому)
3. Собери: дату, значение, единицы, норму, статус

#### Шаг 3: Построение графика

**ASCII-график для терминала:**

Обязательные элементы графика:
1. **Линии границ нормы** — пунктирные горизонтальные линии с подписями
2. **Разные маркеры** для значений в норме и вне нормы
3. **Легенда** с расшифровкой маркеров

```
## Глюкоза — динамика

Норма: 3.9-6.1 ммоль/л
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6.5 ┤                    ◆ ← выше нормы
6.1 ┤─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  верхняя граница
5.5 ┤      ●
5.2 ┤ ●              ●
5.0 ┤                         ●
4.5 ┤
3.9 ┤─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  нижняя граница
3.5 ┤
    └──────┴──────┴──────┴──────┴──────┴───→
     2021   2022   2023   2024   2025  дата

● норма   ◆ выше нормы   ◇ ниже нормы
```

**Правила построения:**
- Границы нормы отображаются пунктирными линиями `─ ─ ─` с подписью
- Шкала Y должна включать границы нормы + запас для отклонений
- Точки вне нормы выделяются другим маркером (◆/◇) и стрелкой-комментарием
- Если норма односторонняя ("<X" или ">X"), показывается только одна линия

#### Шаг 4: Сохранение отчета

**Путь файла:** `Показатели/{Показатель}.md`

**Формат файла:**

```markdown
---
metric: {Название показателя}
unit: {Единицы измерения}
norm: "{Норма}"
generated: {текущая дата YYYY-MM-DD}
measurements: {число измерений}
period_start: {дата первого измерения}
period_end: {дата последнего измерения}
last_value: {последнее значение}
last_status: normal | high | low
trend: up | down | stable | unknown
---

# {Показатель}

> Обновлено: {текущая дата}
> Измерений: {число} | Период: {первая дата} — {последняя дата}

## График

```mermaid
xychart-beta
    title "{Показатель} ({единицы})"
    x-axis [{даты}]
    y-axis "Значение" {min} --> {max}
    line "Значения" [{значения}]
    line "Верхняя граница" [{верхняя_граница повторенная N раз}]
    line "Нижняя граница" [{нижняя_граница повторенная N раз}]
```

**Примечание к Mermaid-графику:**
- Линии границ нормы показываются горизонтальными линиями
- Если норма задана как "<X" или ">X", показывается только одна граница
- Значения границ повторяются для каждой точки данных

## Все измерения

| Дата | Значение | Норма | Статус | Источник |
|------|----------|-------|--------|----------|
| {дата} | {значение} {единицы} | {норма} | {статус} | [[путь к анализу]] |

**Обозначения статуса в таблице:**
- ✓ норма — значение в пределах референса
- **↑ высокий** — значение выше нормы (выделить жирным)
- **↓ низкий** — значение ниже нормы (выделить жирным)
- **↑↑ критически высокий** — значительное превышение (>2x от границы)
- **↓↓ критически низкий** — значительное снижение

## Статистика

- **Измерений:** {число}
- **Период:** {первая дата} — {последняя дата}
- **Норма:** {референс}
- **Минимум:** {значение} ({дата})
- **Максимум:** {значение} ({дата})
- **Среднее:** {значение}
- **Медиана:** {значение}
- **Тренд:** {↑/↓/→}
- **Отклонений от нормы:** {число} из {всего} ({процент}%)

## Интерпретация

{Краткий анализ динамики показателя, клиническое значение отклонений}

**Рекомендация:** {когда следует повторить анализ}

---
*Отчет сформирован автоматически. Не является медицинским заключением.*
```

#### Шаг 5: Обновление реестра

После сохранения отчета по показателю, проверь наличие ссылки в `Показатели/_registry.md`.

В разделе "Показатели по группам" названия показателей должны быть ссылками:

```markdown
### Клинический анализ крови
- [[Показатели/Лейкоциты (WBC)|Лейкоциты (WBC)]]
- [[Показатели/Гемоглобин (HGB)|Гемоглобин (HGB)]]
- [[Показатели/Эритроциты (RBC)|Эритроциты (RBC)]]
```

Если файл показателя создан — добавь ссылку. Если нет — оставь текст без ссылки.

#### Шаг 6: Вывод результата

После сохранения выведи:

```
## Отчет сохранен

**Файл:** [[Показатели/{Показатель}]]
**Измерений:** {число}
**Период:** {первая дата} — {последняя дата}
**Последнее:** {значение} ({статус})
**Тренд:** {↑/↓/→}
```

### Сравнение нескольких показателей

При вызове `/med-metrics Глюкоза,Гемоглобин`:

1. Создай отчеты для каждого показателя
2. Выведи сравнительную таблицу

```
## Сравнение показателей

| Дата | Глюкоза | Гемоглобин |
|------|---------|------------|
| 2025-02 | 5.0 ммоль/л | — |
| 2023-04 | 6.5 ммоль/л | 150 г/л |

**Сохранены отчеты:**
- [[Показатели/Глюкоза]]
- [[Показатели/Гемоглобин]]
```

### Флаг --abnormal

При вызове `/med-metrics --abnormal`:

1. Выведи таблицу показателей вне нормы
2. Для каждого создай/обнови отчет
3. Предложи выбрать показатель для детального анализа

## Расчет тренда

Тренд определяется по последним 3 измерениям:
- **↑ рост** — последнее значение > среднего предыдущих на >10%
- **↓ снижение** — последнее значение < среднего предыдущих на >10%
- **→ стабильно** — колебания в пределах 10%
- **— недостаточно данных** — менее 2 измерений

## Примечания

- Показатели ищутся по точному совпадению названия
- При повторном вызове файл показателя перезаписывается с актуальными данными
- Имя файла = название показателя (пробелы сохраняются)
- Графики адаптируются под количество измерений
