# Skill: med-init

Инициализация медицинского волта Obsidian.

## Описание

Этот skill создает полную структуру папок и файлов для медицинского волта Obsidian, готового к использованию с медицинскими скиллами MedSkill.

## Использование

```
/med-init
```

## Что делает skill

1. Создает структуру папок для медицинских документов
2. Создает базовые файлы направлений
3. Создает файл README с инструкциями по использованию
4. Создает `.gitkeep` файлы для сохранения структуры в git (опционально)

## Инструкции

### Шаг 1: Проверка текущей директории

1. Получи текущую директорию с помощью `pwd`
2. Спроси пользователя подтверждение:
   ```
   Вы хотите инициализировать медицинский волт в текущей директории?
   Путь: {текущая_директория}

   Будет создана следующая структура:
   - inbox/ (для необработанных документов)
   - Документы/ (для обработанных документов)
     - Анализы/
     - Консультации/
     - Исследования/
     - Выписки/
   - Направления/ (индексы по медицинским направлениям)
   - Истории/ (аналитические отчеты)
   - Показатели/ (динамика показателей)

   Продолжить? (y/n)
   ```

3. Если пользователь отказывается - завершить работу с сообщением о том, как перейти в нужную директорию

### Шаг 2: Создание структуры папок

Создай следующие папки:

```bash
mkdir -p inbox
mkdir -p Документы/Анализы
mkdir -p Документы/Консультации
mkdir -p Документы/Исследования
mkdir -p Документы/Выписки
mkdir -p Направления
mkdir -p Истории
mkdir -p Показатели
```

### Шаг 3: Создание базовых файлов направлений

Создай файлы в папке `Направления/` для основных медицинских направлений:

#### Направления/Терапия.md

```markdown
# Терапия

## Хронология

### 2025

#### Консультации

#### Анализы

#### Исследования

#### Выписки
```

Создай аналогичные файлы для следующих направлений:
- Терапия.md
- Гастроэнтерология.md
- Неврология.md
- Кардиология.md
- Эндокринология.md
- Офтальмология.md
- Стоматология.md
- Дерматология.md
- Ревматология.md
- Пульмонология.md

Каждый файл должен иметь одинаковую структуру с разделами для консультаций, анализов, исследований и выписок.

### Шаг 4: Создание регистра показателей

Создай файл `Показатели/_registry.md`:

```markdown
# Реестр показателей

> Последнее обновление: {текущая дата}

## Сводка

Регистр будет автоматически заполнен после обработки первых анализов.

Используйте `/med-index` для индексации документов и обновления этого файла.

## Как добавить показатели

1. Поместите PDF/JPG документ с анализами в папку `inbox/`
2. Запустите `/med-process-inbox`
3. Скилл автоматически извлечет показатели и обновит регистр

## Просмотр динамики показателей

Используйте команду:
```
/med-metrics                    # Список всех показателей
/med-metrics Глюкоза            # График конкретного показателя
/med-metrics --abnormal         # Только отклонения от нормы
```
```

### Шаг 5: Создание README для волта

Создай файл `README.md` в корне волта:

```markdown
# Медицинский волт

Этот Obsidian волт предназначен для хранения и анализа медицинских записей с использованием Claude Code и скиллов MedSkill.

## Структура

- **inbox/** - папка для необработанных документов (PDF, JPG, PNG)
- **Документы/** - обработанные медицинские документы
  - Анализы/
  - Консультации/
  - Исследования/
  - Выписки/
- **Направления/** - индексы документов по медицинским направлениям
- **Истории/** - аналитические отчеты по направлениям
- **Показатели/** - динамика медицинских показателей

## Быстрый старт

### 1. Обработка нового документа

1. Поместите PDF или изображение медицинского документа в папку `inbox/`
2. Запустите Claude Code в директории волта:
   ```bash
   cd /path/to/this/vault
   claude
   ```
3. В Claude Code выполните:
   ```
   /med-process-inbox
   ```

Скилл автоматически:
- Распознает тип документа (анализ, консультация, исследование, выписка)
- Извлечет данные и показатели
- Создаст структурированный MD файл
- Обновит файл направления
- Регенерирует историю болезни (если существует)
- Обновит графики показателей (для анализов)

### 2. Анализ истории болезни

```
/med-history Гастроэнтерология
```

Создаст структурированный отчет с:
- Хронологией обращений
- Диагнозами и их динамикой
- Ключевыми показателями
- Рекомендациями по дообследованию
- Вопросами для врача

### 3. Сводный анализ всех направлений

```
/med-merge-history
```

Создаст сводную историю с:
- Корреляциями между диагнозами разных направлений
- Гипотезами о системных проблемах
- Комплексным планом обследования

### 4. Мониторинг показателей

```
/med-metrics                    # Список всех показателей
/med-metrics Глюкоза            # График динамики глюкозы
/med-metrics --abnormal         # Только отклонения от нормы
```

### 5. Индексация документов

```
/med-index
```

Обновляет:
- Файлы направлений в `Направления/`
- Регистр показателей в `Показатели/_registry.md`

## Доступные скиллы

- `/med-process-inbox` - обработка документов из inbox
- `/med-history <Направление>` - история болезни по направлению
- `/med-index` - индексация всех документов
- `/med-merge-history` - сводная история с корреляциями
- `/med-metrics [показатель]` - динамика показателей

## Типичный workflow

### Ежемесячный медосмотр
1. Получили результаты анализов → сохраните PDF в `inbox/`
2. `/med-process-inbox` → документ обработан
3. `/med-metrics --abnormal` → проверка отклонений
4. `/med-history <направление>` → обновление истории

### Подготовка к приему специалиста
1. `/med-history <направление>` → история по направлению
2. `/med-merge-history` → сводная история
3. Откройте файлы в Obsidian
4. Используйте раздел "Вопросы для врача"

## Дополнительная информация

Полная документация по скиллам MedSkill:
https://github.com/yourusername/MedSkill

**ВАЖНО:** Этот волт содержит медицинскую информацию. Убедитесь, что:
- Волт хранится на зашифрованном диске
- Резервные копии защищены
- Не синхронизируйте с публичными сервисами без шифрования
```

### Шаг 6: Создание .gitkeep файлов (опционально)

Спроси пользователя:
```
Хотите добавить .gitkeep файлы для сохранения структуры папок в git? (y/n)
```

Если да, создай пустые `.gitkeep` файлы в пустых папках:
- `inbox/.gitkeep`
- `Истории/.gitkeep`

### Шаг 7: Создание .gitignore (опционально)

Спроси пользователя:
```
Хотите создать .gitignore для исключения конфиденциальных данных? (y/n)
```

Если да, создай файл `.gitignore`:

```
# Необработанные документы (могут содержать персональные данные)
inbox/*
!inbox/.gitkeep

# Obsidian
.obsidian/
.trash/

# macOS
.DS_Store

# Backup files
*.backup
*~

# ВАЖНО: Раскомментируйте строки ниже, если хотите исключить обработанные документы
# Документы/
# Направления/
# Истории/
# Показатели/
```

## Примечания

- Skill проверяет, не существуют ли уже папки, и не перезаписывает существующие файлы
- Если структура уже частично создана, skill создает только недостающие элементы
- Все файлы создаются в текущей директории
- Рекомендуется запускать skill в пустой директории для создания нового волта

## Безопасность

- Напомни пользователю о необходимости защиты медицинских данных
- Предложи использовать шифрование для хранения волта
- Предупреди об осторожности с облачной синхронизацией
