# Skill: med-index

Индексация документов медицинского хранилища.

## Описание

Этот skill сканирует все документы в `Документы/`, обновляет файлы направлений и регистр показателей.

## Использование

```
/med-index
```

## Что делает skill

1. **Индексирует документы по направлениям** - заполняет файлы в `Направления/` явными ссылками на документы
2. **Собирает регистр показателей** - обновляет `Показатели/_registry.md` со статистикой по каждому показателю

## Инструкции

### Шаг 1: Сканирование документов

1. Найди все MD файлы в `Документы/` (Анализы, Консультации, Исследования, Выписки)
2. Для каждого файла извлеки из YAML frontmatter:
   - `date` - дата документа
   - `type` - тип (анализ, консультация, исследование, выписка)
   - `direction` - медицинское направление
   - `category` - категория документа
   - `metrics` - показатели (только для анализов)

### Шаг 2: Обновление файлов направлений

Для каждого направления в `Направления/`:
- Терапия, Кардиология, Эндокринология, Гастроэнтерология
- Неврология, Офтальмология, Стоматология, Дерматология
- Ревматология, Хирургия, Пульмонология (и другие если есть)

Обнови файл направления по шаблону:

```markdown
# {Направление}

## Хронология

### {Год}

#### Консультации
- [[Документы/Консультации/{Год}/{Файл}|{Дата} - {Описание}]]

#### Анализы
- [[Документы/Анализы/{Год}/{Файл}|{Дата} - {Категория}]]

#### Исследования
- [[Документы/Исследования/{Год}/{Файл}|{Дата} - {Категория}]]

#### Выписки
- [[Документы/Выписки/{Год}/{Файл}|{Дата} - {Описание}]]
```

**Правила:**
- Группируй документы по годам (от нового к старому)
- Внутри года группируй по типу документа
- Используй Obsidian ссылки `[[путь|название]]`
- Пропускай пустые разделы (если нет документов этого типа за год)
- Если направление документа не соответствует существующим файлам, создай новый файл

### Шаг 3: Обновление регистра показателей

Обнови файл `Показатели/_registry.md`:

1. Собери все показатели из всех анализов
2. Для каждого уникального показателя посчитай:
   - Количество измерений
   - Дату первого и последнего измерения
   - Последнее значение и статус
   - Тренд (рост/снижение/стабильно)

Формат файла:

```markdown
# Реестр показателей

> Последнее обновление: {текущая дата}

## Сводка

| Показатель | Измерений | Период | Последнее | Тренд |
|------------|-----------|--------|-----------|-------|
| Глюкоза | 5 | 2021-2025 | 5.2 ммоль/л (норма) | → |
| Гемоглобин | 8 | 2019-2025 | 148 г/л (норма) | ↑ |

**Условные обозначения:**
- ↑ рост (последние значения выше предыдущих)
- ↓ снижение (последние значения ниже предыдущих)
- → стабильно (колебания в пределах 10%)
- — недостаточно данных для определения тренда

## Показатели вне нормы

Список показателей, где последнее измерение отклоняется от нормы:

| Показатель | Значение | Норма | Статус | Дата |
|------------|----------|-------|--------|------|
| СКФ | 79 мл/мин | 90-200 | низкий | 2022-02-12 |

## Показатели по группам

### Клинический анализ крови
- Лейкоциты (WBC)
- Гемоглобин (HGB)
...

### Биохимия крови
- Глюкоза
- Креатинин
...
```

### Шаг 4: Вывод отчета

После индексации выведи сводку:

```
## Индексация завершена

### Направления
- Гастроэнтерология: 15 документов
- Терапия: 8 документов
- Неврология: 12 документов
...

### Показатели
- Всего уникальных показателей: 45
- Показателей вне нормы: 3
- Последнее обновление анализов: 2025-02-15

### Изменения
- Обновлено файлов направлений: 5
- Обновлен регистр показателей
```

## Примечания

- Показатели с одинаковым названием но разными единицами считаются разными показателями
- При повторном запуске skill полностью перезаписывает файлы направлений и регистр
