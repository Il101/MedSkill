# Skill: med-merge-history

Формирование сводной истории болезни с анализом корреляций между направлениями.

## Описание

Этот skill анализирует все истории болезни по направлениям, выявляет связи между диагнозами и показателями, формирует комплексную картину состояния здоровья с рекомендациями по подтверждению или уточнению диагнозов.

## Использование

```
/med-merge-history
```

## Что делает skill

1. Читает все истории болезни из папки `Истории/`
2. Анализирует корреляции между диагнозами разных направлений
3. Выявляет связи между показателями и симптомами
4. Формирует хронологию ключевых событий
5. Предлагает гипотезы о системных проблемах
6. Рекомендует исследования для подтверждения/опровержения
7. **Сохраняет отчет в `Истории/_Сводная.md`**

## Инструкции

### Шаг 1: Сбор историй

1. Найди все файлы в папке `Истории/` (кроме `_Сводная.md`)
2. Прочитай каждую историю полностью
3. Извлеки из frontmatter:
   - direction (направление)
   - diagnoses (список диагнозов со статусами)
   - period_start, period_end
   - documents_count

### Шаг 2: Построение единой картины

Создай структуру данных:

**Все диагнозы:**
- Сгруппируй по статусу (активные, в ремиссии, сняты)
- Отметь дату установления каждого

**Единая хронология:**
- Объедини события из всех историй
- Отсортируй по дате
- Отметь совпадения по времени

**Показатели:**
- Собери все упомянутые показатели
- Отметь отклонения от нормы
- Найди показатели, упоминаемые в нескольких направлениях

### Шаг 3: Анализ корреляций

#### 3.1 Корреляции диагнозов

Проверь известные медицинские связи:

**Метаболические:**
- Ожирение + гипертония + дислипидемия → метаболический синдром
- Сахарный диабет + кардиопатия + нефропатия → диабетические осложнения
- Гипертиреоз/гипотиреоз + кардиальные нарушения → тиреогенная кардиопатия

**ЖКТ и системные:**
- Хронический гастрит + анемия → возможный дефицит B12/железа
- Мальабсорбция + остеопороз → недостаток кальция/витамина D
- Хронические заболевания печени + коагулопатия

**Кардио-ренальные:**
- Сердечная недостаточность + почечная недостаточность → кардиоренальный синдром
- Артериальная гипертензия + хроническая болезнь почек → нефрогенная гипертензия
- Ишемическая болезнь сердца + сахарный диабет → ускоренный атеросклероз

**Неврология и другие:**
- Мигрень + кардиоваскулярные нарушения → сосудистый компонент
- Полинейропатия + сахарный диабет → диабетическая нейропатия
- Когнитивные нарушения + сосудистая патология → дисциркуляторная энцефалопатия

**Аутоиммунные:**
- Множественные аутоиммунные проявления в разных органах → полиаутоиммунность
- Аутоиммунное заболевание + семейный анамнез → генетическая предрасположенность

#### 3.2 Корреляции показателей

Найди показатели, которые:
- Отклонялись в нескольких анализах
- Связаны с несколькими направлениями
- Показывают устойчивый тренд

#### 3.3 Временные корреляции

Выяви:
- События, произошедшие в близкие даты
- Последовательности: симптом → диагноз → лечение
- Обострения, совпадающие по времени

### Шаг 4: Формирование гипотез

На основе корреляций сформулируй:

**Подтвержденные связи:**
- Диагнозы, подтвержденные несколькими источниками
- Корреляции с доказательной базой

**Гипотезы для проверки:**
- Возможные системные заболевания
- Связи, требующие дообследования
- Альтернативные объяснения симптомов

**Противоречия:**
- Диагнозы, не согласующиеся друг с другом
- Показатели, противоречащие диагнозам
- Пробелы в обследованиях

## Известные медицинские корреляции

### Метаболический синдром

Комбинация 3+ из:
- Абдоминальное ожирение (окружность талии >94 см у мужчин, >80 см у женщин)
- Гипертриглицеридемия (>1.7 ммоль/л)
- Низкий ЛПВП (<1.0 ммоль/л у мужчин, <1.3 ммоль/л у женщин)
- Артериальная гипертензия (>130/85 мм рт. ст.)
- Гипергликемия натощак (>5.6 ммоль/л)

→ Единый патогенез, требует комплексного подхода: диета, физическая активность, медикаментозная терапия

### Кардиоренальный синдром

Взаимосвязь сердечной и почечной патологии:
- Хроническая сердечная недостаточность → снижение почечной перфузии
- Хроническая болезнь почек → объемная перегрузка и гипертензия
- Сахарный диабет → поражение обеих систем

→ Требует кардионефрологического подхода, мониторинга обеих функций

### Диабетические осложнения

Сахарный диабет часто приводит к:
- Диабетическая нефропатия (снижение СКФ, протеинурия)
- Диабетическая ретинопатия (поражение сосудов сетчатки)
- Диабетическая полинейропатия (нарушение чувствительности)
- Диабетическая ангиопатия (поражение крупных и мелких сосудов)
- Диабетическая стопа (язвы, гангрена)

→ Требует строгого контроля гликемии, регулярного скрининга осложнений

### Анемия и ЖКТ патология

Хронические заболевания ЖКТ могут приводить к анемии:
- Хронический гастрит (особенно атрофический) → дефицит B12
- Целиакия/мальабсорбция → дефицит железа, фолиевой кислоты
- Хронические кровопотери (язвы, полипы) → железодефицитная анемия
- Заболевания печени → нарушение метаболизма железа

→ Требует гастроэнтерологического обследования при необъяснимой анемии

### Тиреогенные нарушения

Патология щитовидной железы влияет на многие системы:
- Гипертиреоз → тахикардия, фибрилляция предсердий, остеопороз
- Гипотиреоз → брадикардия, гиперхолестеринемия, депрессия
- Аутоиммунный тиреоидит → риск других аутоиммунных заболеваний

→ Требует мониторинга ТТГ и системных проявлений

### Хронические заболевания печени

Цирроз печени приводит к системным нарушениям:
- Коагулопатия (снижение синтеза факторов свертывания)
- Портальная гипертензия (варикоз пищевода, асцит)
- Печеночная энцефалопатия (нарушения сознания)
- Гепаторенальный синдром (почечная недостаточность)

→ Требует гепатологического мониторинга, профилактики осложнений

## Примечания

- Skill анализирует только файлы из папки `Истории/`
- При повторном запуске файл `_Сводная.md` перезаписывается
- Гипотезы носят информационный характер и требуют врачебной оценки
- Корреляции основаны на известных медицинских связях, но не являются диагнозом
- Приоритет обследований определяется на основе выявленных связей
