# Skill: med-history

Анализ истории болезни по медицинскому направлению.

## Описание

Этот skill анализирует все документы по выбранному направлению, формирует структурированную историю болезни и сохраняет её в реестр.

## Использование

```
/med-history Гастроэнтерология
/med-history Кардиология
/med-history Эндокринология
```

## Что делает skill

1. Собирает все документы по направлению
2. Анализирует хронологию обращений
3. Выделяет диагнозы и их изменения
4. Оценивает динамику показателей
5. Формирует рекомендации по дообследованию
6. **Сохраняет отчет в `Истории/{Направление}.md`**

## Инструкции

### Шаг 1: Сбор документов

1. Получи название направления из аргумента команды
2. Найди файл направления в `Направления/{Направление}.md`
3. Собери все связанные документы из `Документы/` где `direction` = указанное направление
4. Прочитай каждый документ полностью

### Шаг 2: Анализ документов

Для каждого документа извлеки:

**Консультации:**
- Дата и врач
- Жалобы пациента
- Диагнозы (основной и сопутствующие)
- Назначения и рекомендации

**Анализы:**
- Дата и категория
- Показатели вне нормы
- Клинически значимые изменения

**Исследования:**
- Дата и тип исследования
- Заключение
- Выявленные патологии

**Выписки:**
- Даты госпитализации
- Диагнозы при выписке
- Проведенное лечение
- Рекомендации

### Шаг 3: Формирование и сохранение отчета

**Путь файла:** `Истории/{Направление}.md`

Создай папку `Истории/` если не существует.

**Формат файла:**

```markdown

```

### Шаг 5: Логика рекомендаций

При формировании рекомендаций учитывай:

**Анализы:**
- Если анализ не сдавался > 1 года — рекомендовать повторить
- Если показатель был вне нормы — рекомендовать контроль
- Стандартные скрининги по направлению

**Исследования:**
- Если исследование не проводилось > 2 лет — оценить необходимость
- Если выявлена патология — рекомендовать динамику

**Консультации:**
- Если не было осмотра > 1 года — рекомендовать визит
- Если есть смежные проблемы — рекомендовать профильного специалиста

### Специфика по направлениям

**Гастроэнтерология:**
- Повторная ЭГДС/колоноскопия при выявленной патологии
- Анализы на H.pylori при гастрите/язве
- Контроль печеночных проб при заболеваниях печени
- Специфические маркеры при хронических заболеваниях кишечника

**Эндокринология:**
- Контроль ТТГ, Т4 при патологии щитовидной железы
- УЗИ щитовидной железы в динамике
- Контроль витамина D, кальция, ПТГ

**Офтальмология:**
- Контроль остроты зрения и рефракции
- Измерение внутриглазного давления при глаукоме
- Осмотр глазного дна при диабетической ретинопатии
- ОКТ при дегенеративных заболеваниях сетчатки

**Неврология:**
- МРТ головного мозга/позвоночника в динамике
- ЭЭГ при эпилепсии
- УЗДГ/дуплекс сосудов

**Кардиология:**
- ЭКГ, ЭхоКГ в динамике
- Липидный профиль
- Контроль АД

## Примечания

- Skill анализирует только документы с указанным направлением в frontmatter
- При повторном запуске файл истории перезаписывается с актуальными данными
- Рекомендации носят информационный характер
- При отсутствии документов по направлению выводится соответствующее сообщение
